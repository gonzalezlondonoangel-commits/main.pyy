
# CLASSNOTE

### Calculadora matemática inteligente

CLASSNOTE es una aplicación desarrollada en Python y Kivy que permite resolver operaciones matemáticas y visualizar sus procedimientos paso a paso.

## Funciones principales

- Suma, resta, multiplicación y división.
- Potenciación.
- Radicación.
- Porcentajes.
- Promedios.
- Valor absoluto.
- Operaciones lógicas.
- Comparaciones matemáticas.
- Procedimientos paso a paso.

## Tecnologías utilizadas

- Python 3
- Kivy
- Abstract Syntax Trees (AST)

## Diseño

La aplicación utiliza una combinación de azul, azul oscuro y amarillo.

## Autor

Angel

## Objetivo

Facilitar el aprendizaje y la resolución de operaciones matemáticas mediante una calculadora interactiva.
